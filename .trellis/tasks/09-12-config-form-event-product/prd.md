# 事件编排共享合同与完整交互

## 目标

按父任务批准合同 AC2/3/4/9，依据 FormCreate Pro 实际产品操作，提供普通用户不写 JSON 即可完成的事件流程，并让公开表单、工作台和独立源码执行等价。

## 需求

- 事件入口清晰，支持有序动作、嵌套条件、分支插入、排序、复制、删除与结束/阻断。
- 根据动作元数据提供类型匹配的控件；字段/变量/事件参数/可用上游输出可以选择。
- 草稿隔离，保存单个 ProjectCommand，取消不改变正式配置；错误定位到事件/步骤/参数，冲突不覆盖。
- 生命周期覆盖初始化、挂载/卸载、值变化、提交前/提交、校验成功/失败、重置、组件注册事件。
- 复用唯一 Core 执行器，明确并发/超时/取消/执行异常继续或中断/阻断语义；有有界trace和重入保护。
- 缺失字段、不可达输出、无效条件与表达式不能静默成功；宿主缺能力明确诊断。
- 常用动作覆盖赋值、状态、校验/提交/重置、数据请求、消息确认、导航延迟与注册扩展。

## 验收

- [ ] Core 作者树到执行图及嵌套分支、引用、策略回归通过。
- [ ] 表单提交阻断、生命周期顺序、取消及重入场景通过。
- [ ] 编辑器普通操作无手写 JSON/内部ID，保存取消/复制排序有浏览器测试。
- [ ] 双组件库直接Runtime/Preview/Source事件执行一致。
- [ ] 调试可读输入输出、时间/耗时与定位错误，记录有上限。

## 依赖与边界

变量/数据源和数组行作用域来自后续共享模块，不在工作台另造私有实现。先冻结Core合同，再并行编辑器及表单接入；最终验收必须与父任务数据、明细和导出场景合并。无任意 JavaScript，不兼容旧逻辑，不删除现有有效能力或回滚用户改动。
