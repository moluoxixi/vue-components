# ConfigForm 工作台界面优化实现记录

本次实现对应 [2026-10-11 界面审查](../ui-layout-audit-2026-10-11/README.md)，覆盖项目、页面、模板、数据管理，项目与模板设计器，从模板创建，体验和源码交付。

管理页保留白色主工作区，通过紧凑列表、细分隔线和少量强调色组织内容。项目和页面默认使用列表，模板默认使用卡片；三个管理入口均可切换显示方式，并分别记住选择。切换视图保留当前搜索条件。

| 区域       | 已实现的行为                                                                                                                             | 1366×768 实测变化                                                              |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 项目与页面 | 紧凑列表、卡片切换；点击卡片或列表行进入，编辑图标独立操作；复制、导出、移动和删除集中在更多菜单；删除仍需确认                           | 项目列表行约 78px、页面列表行约 76px                                           |
| 模板管理   | 根据可用宽度自动排列卡片，描述压缩为一行，提供列表视图                                                                                   | 卡片约 409px → 289px；桌面 4 列，1920px 窗口 6 列                              |
| 从模板创建 | 合并外层标题、类型选择和关闭操作；直接显示页面、弹窗或抽屉 UI，底部保留创建动作；正常模板不再重复提示可用性                              | 预览区约 314px → 543px                                                         |
| 设计器     | 属性默认收起，选中节点后展开；新增专注画布并恢复原有面板状态；记住面板布局；保留物料面板宽度、拖宽和滚动能力                             | 无选择时画布获得原先属性面板占用的空间                                         |
| 属性与物料 | 响应式配置改为设备标签切换并跟随画布设备；数值和枚举使用同行布局；统一字号；物料双列显示，名称允许换行                                   | 辅助信息至少 12px，属性分组不再随根字号缩到约 10px                             |
| 数据管理   | 标题区整合数据视图切换；列支持鼠标和键盘调宽、固定、隐藏、适应内容和重置；按项目和数据集保存列设置；窄屏自动使用可展开、可编辑的记录视图 | 表格起点 y=222px → 191px，可用高度 500px → 531px；320px 下起点 y=279px → 248px |
| 体验       | 使用整个工作区高度，体验状态按需展开                                                                                                     | 面板约 599px → 712px                                                           |
| 源码交付   | 标题、导出模式、样式与下载集中在同一栏，小窗口自动换行                                                                                   | Monaco 编辑区约 547px 高                                                       |

320px 下保留工作模式、保存、撤销/重做和画布设备切换，其他画布命令进入更多菜单。触屏设备的画布按钮使用 44px 点击区域，工具栏高度同步调整，避免按钮被相邻画布裁切。

检查使用独立浏览器上下文和测试项目，覆盖中文、英文，1366×768、1280×540、1024×600、1920×1080、390×844、320×568，以及触屏模式。浏览器回归覆盖视图偏好恢复、搜索保留、列布局恢复、数据排序后编辑原记录、手机完整记录编辑、专注画布恢复、体验全高、键盘导航和可访问性。Windows 和 Linux 的视觉基线分别由对应平台实际生成。

显示偏好保存在本机浏览器，列布局与数据内容独立；隐藏列不会删除列或修改记录。项目、数据与模板继续使用原有存储与保存流程。

本地验证结果：工作台单元测试 668 项通过，设计器单元测试 244 项通过，模板集成测试 6 项通过。浏览器回归扩展至 121 项，并针对外观切换、弹窗可访问性和视觉比对完成 19 项定向回归；弹窗布局修复后的 11 项目录、视觉和尺寸回归全部通过。Windows 基线由 Windows 浏览器生成，Linux 基线经 GitHub CI 容器的实际截图核对并校准字体差异。

创建弹窗的视觉与可访问性检查等待进场动画结束，动画取消后重新检查当前状态；外观设置的更多菜单定位限定在顶部栏，避免匹配选中节点的同名操作。所有原有行为、视觉和可访问性断言继续保留。

创建弹窗去除 Element Plus 默认的 50px 底部外边距，防止手机和较矮窗口出现额外外层滚动。回归检查同时断言外层滚动高度与滚动位置均为零，覆盖 1440×900、1366×768、1280×540、900×900、390×844、320×568。

页面卡片进一步压缩为约 207–209px 高，保留完整预览。名称、路由、重命名和更多操作合并到紧凑的信息区，类型和首页标记保留在预览上；点击预览、信息和空白区域均可打开设计器。路由截断后可通过提示查看全文，触屏下的卡片操作使用 44px 点击区域。列表仍作为默认显示方式，切换保留搜索并分别记住各管理入口的偏好。

使用 12 个页面实测：

| 窗口尺寸 | 卡片列数变化 | 首屏完整卡片数变化 |
| -------- | ------------ | ------------------ |
| 1366×768 | 4 → 5        | 8 → 10             |
| 1024×600 | 3 → 3        | 3 → 6              |
| 800×700  | 1 → 3        | 1 → 6              |

页面、弹窗、抽屉可混排。弹层样式编辑按卡片自身宽度切换为单列，尺寸数值和单位各有明确的控件标签；数值框适应可用宽度，展开编辑不会拉高同排其他卡片。桌面混排、样式编辑和 320px 触屏的 WCAG A/AA 检查均无违规。

本次卡片迭代的页面管理、预览和语言单元测试 14 项通过，管理布局与显示偏好 11 项浏览器回归通过；弹层样式修复后，卡片密度、显示偏好与弹层尺寸保存的 3 项定向回归通过。工作台类型检查、ESLint、构建及其三个产物校验通过。

全仓类型检查 74 个任务通过，工作台类型检查、ESLint、工作台构建及其 Element Plus、Monaco、Tailwind 产物校验通过。架构测试 26 项和架构 CLI 检查通过；本机 Windows 的架构 CLI 子进程耗时超过默认 5 秒，因此复跑时仅通过命令行将测试超时设为 30 秒，仓库测试配置保持原值。

卡片导航去除名称后的跳转箭头和重复的“打开设计”按钮。每张页面卡片、列表行保留一个主入口，点击区域覆盖整个条目；编辑图标、更多菜单和弹层样式编辑独立操作。重命名期间停止条目导航，避免输入操作引发跳转。键盘使用 Tab 定位、Enter 或 Space 进入，页面卡片的焦点描边覆盖整张卡片。项目卡片也移除重复的打开提示，仅在加载时显示“打开中”，保持布局稳定。

本次导航调整的页面与项目管理单元测试 11 项、定向交互场景 5 项及模板视觉回归 4 项通过，工作台类型检查、全仓 lint、工作台构建及三个产物校验通过。独立浏览器审查覆盖中文混排卡片、弹层样式、320px 触屏、项目卡片和列表；WCAG A/AA 检查均无违规，并验证 Space 进入、整卡焦点描边和触屏信息区点击进入。视图偏好回归先等待新页面自动保存再刷新，避免测试在保存完成前重新加载项目。
