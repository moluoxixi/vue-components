# 国际化工作台与端到端集成

## 目标

为 `@moluoxixi/i18n-tool` 实现包内 Vue 3 + Element Plus 工作台，将已完成的本地服务协议串联成可用的扫描、AI 翻译、逐项审阅、diff 预览和确认写回流程，并通过真实浏览器与临时 locale 项目完成端到端验收。

## 需求

### R1. 工作台信息架构

- 首屏直接呈现工作台，不增加营销 landing page。
- 紧凑顶栏显示项目名、当前适配器、AI 脱敏状态和必要命令；内部枚举不作为同权重调试信息常驻。
- 主区按配置/资源、翻译审阅、变更预览组织稳定视图或步骤；状态在视图切换时保持。
- 使用 Element Plus 与 `@lucide/vue`，卡片圆角不超过 8px、不嵌套卡片，状态色仅用于成功/警告/错误。

### R2. 扫描与翻译

- UI 展示服务端解析后的配置、资源目录、源语言、目标语言和 scan 摘要，不允许编辑或查看密钥值。
- 显式区分 validating、loading、empty、ready、error 和 cancelled；请求未完成时的空数组不视为空资源。
- 默认只选择缺失/空译文，按目标语言与资源批量翻译；已有译文需主动勾选重译。
- 翻译支持进度、部分失败定位、停止、失败项重试和切换视图不丢失任务状态。

### R3. 审阅与写回

- 审阅表格展示 key、namespace/path、源文本、当前译文、候选译文、校验与覆盖状态。
- 用户可编辑、逐项/批量接受或拒绝候选；只有通过结构与占位符校验的候选可进入 preview。
- diff 明确标记 create/update/overwrite，显示结构化操作和文本差异；已有译文覆盖需要二次确认。
- apply 仅在 preview 有效时可用；stale/conflict 后刷新扫描或重建 preview，不提供强制覆盖快捷路径。

### R4. 可访问性与响应式

- 视图切换使用 tab 或 step 语义与键盘导航；当前阶段不只依赖颜色。
- 状态使用 `role=status`/live region，失败使用 `role=alert`；图标按钮有 accessible name 与 tooltip。
- dialog 支持 Esc、初始焦点和合理焦点归还；处理中始终提供可访问取消按钮。
- 桌面、平板和手机不产生页面级横向溢出；宽表格与 diff 在自身区域滚动。

## 验收标准

- [x] 用户能从合法配置完成 scan、AI 翻译、候选编辑、preview 和 apply，磁盘结果可重新解析。
- [x] 目标文件不存在时显示 create 并成功创建；已有译文默认不覆盖。
- [x] AI 非法输出、占位符变化、部分失败和用户取消不会进入可写状态。
- [x] preview 后外部修改显示冲突并保留外部内容。
- [x] 键盘可完成核心流程，状态和错误可由语义 role 定位。
- [x] 桌面与移动视口无页面横向溢出、文本重叠、不可达命令或 pageerror。
- [x] 组件测试覆盖关键状态机；Playwright 使用真实 dist、本地 BFF、临时 locale fixture 与 stub AI 上游覆盖成功、创建、冲突、取消和错误流程。
- [x] UI 单测、类型检查、构建和 E2E 通过。

## 范围外

- 多项目同时打开、跨刷新任务恢复和翻译历史数据库。
- 浏览器端目录 picker 作为主要配置入口。
- 云端账号、协作审阅和 TMS 集成。
