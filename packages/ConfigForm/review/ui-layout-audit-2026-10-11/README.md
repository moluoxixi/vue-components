# ConfigForm 工作台界面与空间审查

日期：2026-10-11。评估对象是审查时运行于 http://127.0.0.1:4331/ 的 ConfigForm 工作台，覆盖项目管理、模板管理、页面管理、数据管理、项目设计器、模板设计器、创建流程、体验和源码交付。未对其他组件示例和文档站的界面作全面审查。

审查版本：`9162cfa5`。本报告记录界面现状与优化建议，尚未实施所列优化。

检查了 1366×768、1024×600、1920×1080、390×844 和 320×568 等窗口，并对中文和英文界面作了交叉检查。使用独立浏览器上下文与测试项目，没有修改用户浏览器中的项目数据。检查结果来自界面截图、实际元素尺寸及对应布局源码；下方的目标尺寸是建议，并非已经实现的结果。

目前有足够的优化空间，主要集中在内容浏览密度、面板默认状态、重复工具栏和不同工作区的交互一致性。下一轮应建立统一的工作台布局规则，再逐个页面应用。保持白色主工作区，以文字层级、细分隔线和少量强调色表达关系。

空间利用率需要结合任务判断。只有一个项目时的大块空白不构成布局故障；设计画布中的空白也可能是用户正在设计的页面。应优先减少妨碍浏览的卡片高度、无用途的外围空白和重复导航。两侧独立面板可分别滚动；同一内容区不应再嵌套两个承担相同任务的垂直滚动层。

建议分三步实现：

1. 修复布局问题：体验页填满高度、窄窗口命令收纳、长标题与中英文工具栏验证。
2. 改善核心任务：模板/项目/页面列表密度、设计器面板状态、属性编辑和数据表列布局。
3. 统一产品细节：工作区导航、字体与按钮规范、创建弹窗、源码交付工具栏。

验收应在有内容的场景进行：多个项目、至少 12 个模板、多页面项目，以及 60 行含长文本的数据表。1366×768 是主要桌面验收窗口，1024×600 检查小窗口，1920×1080 检查宽屏利用率，390×844 与 320×568 检查入口、保存与单条详情。每个工作区需保证主操作可见、标题不挤出命令、搜索/筛选状态切换后保留上下文、无意外全页横向溢出。

设计参考已经核对：

- [Ant Design 布局规范](https://ant.design/docs/spec/layout/)：按窗口变化动态分配工作区，使用统一网格与间距。
- [Carbon 数据表规范](https://carbondesignsystem.com/components/data-table/usage/)：表格优先获得主要内容宽度，工具栏集中搜索与相关动作，密度与行高配套选择。
- [NN/G 渐进披露](https://www.nngroup.com/articles/progressive-disclosure/)：默认优先展示常用操作，高级或低频功能按需出现，同时保留明确入口。

这些规则用于指导当前业务任务，不照搬示例配色或布局。
