# Utilities

The utility packages share this repository's pnpm workspace, Changesets release flow, and VitePress site while remaining independently installable.

## Runtime Utilities

- [@moluoxixi/utils](./utils): cross-runtime functions and Node.js project manifest utilities
- [@moluoxixi/ajax-package](./ajax-package): an Axios-based HTTP client
- [@moluoxixi/excel](./excel): Excel and CSV data import and export
- [@moluoxixi/indexed-db](./indexed-db): IndexedDB key-value storage

## Tooling

- [@moluoxixi/eslint-config](./eslint-config): shared ESLint configuration factory
- [@moluoxixi/postcss-selector-prefix](./postcss-selector-prefix): selector prefix replacement plugin
- [@moluoxixi/vite-config](./vite-config): dependency-aware Vite configuration preset
