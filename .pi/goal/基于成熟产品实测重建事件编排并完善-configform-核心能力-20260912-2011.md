# Goal

以 **FormCreate Pro 已发布在线产品的真实功能与具体交互** 为主要参照，以 VForm 3 Pro 等成熟产品为补充，重建本项目 ConfigForm 设计器的事件编排，并补齐核心业务表单的功能与交互闭环，使设计器与配置化表单运行时达到下述可验证的生产级基线。

交付覆盖现有 **Element Plus 与 Ant Design Vue**，包含事件编排、变量与数据源、联动、嵌套与表格子表单、校验/提交/重置/只读、设计器交互以及预览、持久化和导入导出。允许重新设计公开 API、Schema 与事件协议，删除旧实现，不承担旧逻辑兼容或旧数据迁移。

以 Trellis 父任务及可独立验收的子任务记录本次工作；交付不是仅完成调研、重构内核或修改界面，而是以下功能和质量标准全部得到验证。

# Acceptance criteria

1. **有真实产品操作证据的调研与差距清单。** 交付调研记录，至少覆盖 FormCreate Pro 官方在线演示（`https://pro.form-create.com/view/`）与 VForm 3 Pro 官方在线演示（`http://pro3.vform666.com/`）。记录访问日期、URL、可获取的版本信息、具体操作路径、截图及观察结果；覆盖事件入口、动作与条件配置、字段/变量引用、数据源、子表单、校验、预览和导入导出。明确区分亲自操作验证、仅由文档描述以及无法访问的能力，不把开源实现等同于商业产品。差距清单逐项关联本次实现与验收证据，或说明不采用/不纳入的理由；本合同明确包含的能力不得仅列入后续路线图。

2. **事件编排是可独立完成业务任务的可视化产品。** 用户可以从表单及组件事件入口创建、查看、编辑、复制、删除流程，通过界面完成顺序动作、条件分支、嵌套条件、动作排序和结束/阻断设置。内置动作使用匹配其参数的配置控件，字段、变量、事件参数及上游结果有可发现的选择入口；常用流程不要求手写 JSON、内部节点 ID、连线协议或 JavaScript。配置错误可以定位到具体事件、节点及参数。取消不改变正式配置，保存进入统一撤销/重做历史；重新打开配置无信息丢失。上述行为有浏览器交互测试。

3. **事件与动作能力形成闭环。** 支持初始化/挂载/卸载、值变化、提交前/提交、校验成功/失败、重置和组件注册事件，并有明确且经测试的触发时机、顺序、参数及作用域。动作至少包含字段/变量赋值、显隐/禁用/只读、校验、提交、重置、数据源或 HTTP 请求、消息、确认、导航、延时和宿主注册的自定义动作。顺序与分支、结果引用、执行条件、异常继续/中断及显式阻断均有行为测试。自定义动作可声明参数配置与诊断，不需要修改编排器内部代码才能接入。

4. **异步执行可靠且可诊断。** 流程具有明确的并发策略、超时、取消和错误处理；快速连续触发、请求乱序、组件删除、页面/项目切换及卸载不会让过期结果覆盖新状态。赋值引起的事件和联动具有可测试的重入/循环保护。调试界面可以查看运行状态、节点执行顺序、输入输出、耗时和错误定位，记录数量有上限。使用可控测试请求证明成功、失败、超时、取消和并发场景，而非只检查生成代码的字符串。

5. **变量、数据源和联动可复用、可配置、可测试。** 支持表单级变量的声明、初始值、读取和更新；支持命名数据源的请求方法、地址、参数、请求头、请求体及结果映射，并提供显式测试、加载、空结果和错误反馈。字段选项与事件动作可以引用同一数据源，支持依赖字段变化后的级联更新和过期请求隔离。同步计算、条件联动与异步事件职责清晰，不发生相互覆盖或无限触发。字段/变量重命名、复制和删除后，受支持的结构化引用与表达式引用正确更新，或给出阻止错误运行的明确诊断。

6. **嵌套及明细表单在设计态和运行态完整可用。** 支持对象嵌套、可重复数组子表单及表格形式的明细编辑，包含至少两层嵌套测试。数组行支持新增、复制、删除、排序和数量约束；行内值、默认值、校验、联动、事件及错误定位按正确作用域运行，增删和排序后不串行、不丢值。设计器可配置这些结构，运行时可回填、编辑、提交、重置和只读展示，序列化往返保持语义。

7. **配置化表单具备一致的业务状态语义。** 必填、同步/异步校验、触发时机、跨字段与子表单校验、错误定位、默认值、回填、脏状态、触达状态、隐藏/禁用/只读及其提交语义均有明确合同与自动化测试。无效表单不能误提交；重复提交与进行中的异步校验有确定行为；重置能恢复约定的初始状态。Element Plus 和 Ant Design Vue 使用同一场景矩阵验证值类型、事件与状态一致性。

8. **设计器核心操作无功能断点。** 物料搜索与添加、拖入及跨容器移动、嵌套定位、图层选择与排序、属性编辑、复制粘贴、删除、撤销重做、保存恢复和预览均有端到端覆盖。无效操作有原因反馈，不静默失败；编辑错误不会损坏正式项目。桌面设计工作流在 `1280×800` 与 `1440×900` 下验证面板、弹窗、菜单、焦点恢复及键盘操作；表单在 `375×812`、`768×1024` 与 `1440×900` 下验证布局与交互，无非预期文字遮挡或页面横向溢出。

9. **设计、运行、保存与导出语义一致。** 同一设计产物可以在工作台预览、业务应用直接集成的 ConfigForm，以及导出的独立 Vue 工程中运行；事件、数据源、联动、校验和子表单不成为仅工作台可用的功能。项目及页面 JSON 导出、重新导入、保存重开后语义保持，复制产生的新实例引用正确。独立 Vue 导出工程能完成依赖安装与构建，并执行代表性业务场景；自定义宿主动作缺少所需导出绑定时必须明确诊断，不允许静默丢弃逻辑。

10. **有可复现的生产级验收场景和质量证据。** 两套组件库均至少通过三个完整场景：动态选项与条件校验的资料表单、含嵌套明细与计算的订单表单、含确认/异步请求/成功失败分支的提交表单。场景覆盖设计、预览、修改、撤销、保存重开及导出运行。ConfigForm 范围现有及新增的单元/集成测试、类型检查、构建和性能预算测试通过，受影响代码的 lint 通过；工作台 `test`、`typecheck`、`build`、`verify:templates` 和 `test:e2e` 对应命令成功退出。关键页面无未处理异常，关键工作流的无障碍扫描无 serious/critical 级违规。不得通过跳过关键用例、删除有效断言或放宽预算来宣称通过；环境阻塞必须单独列明，未验证项目不得标记完成。

11. **架构与使用文档可支撑后续开发。** 更新 ConfigForm 架构文档、相关公开 API/Schema/扩展文档、示例、路线图及受影响的项目规范，说明新的事件时序、状态所有权、数据源/变量/子表单作用域、安全与宿主能力边界。文档及示例不再引导使用已删除的旧事件路径；交付摘要列出破坏性变化、验证命令及结果，并与 Trellis 任务验收记录一致。

# Boundaries

- 本次是**核心业务表单生产级**交付，不以复刻 FormCreate Pro 全部商业功能、所有组件或视觉皮肤作为目标；产品调研用于功能和交互决策，不以获取、复制商业源代码为前提。
- 保持本项目配置化表单与设计器的自主实现及现有 Element Plus、Ant Design Vue 支持，不把产品整体替换成 FormCreate/VForm。不因重写事件流程而静默取消现有核心能力。
- **不提供任意 JavaScript 执行。** 配置使用安全表达式与显式注册的宿主动作；配置导入不能通过 `eval`、`Function` 或等效入口执行代码。宿主业务代码属于明确的可信扩展边界。
- 请求、导航和交互副作用通过明确的宿主能力边界执行。设计态、配置编辑与导入本身不得自动触发外部业务副作用；测试使用隔离数据和可控请求，不向真实业务端点提交数据。
- 可以破坏性更改 Schema、API 和包内职责并删除旧实现，无需兼容层或迁移工具。旧格式应明确拒绝，不做猜测式转换；不得擅自清空用户项目、已有持久化数据或 Git 历史。
- 范围限于 `packages/ConfigForm`、必要的直接集成点、相关测试/示例/文档/Trellis 记录及确有需要的依赖配置，不夹带无关包重构。
- 不包含 AI 表单助理、图表大屏、额外移动端 UI 组件库、服务端表单管理/审批平台、账号权限平台、多用户协同服务或正式部署；现有组件库的响应式表单渲染仍在范围内。
- 不购买商业授权、不绕过登录或付费限制、不使用他人凭据。无法访问的产品能力必须标记证据限制；若其直接阻塞验收，明确说明阻塞及已尝试的替代验证方式。
- 目标批准前不创建任务文件或修改业务代码；批准后按已同意的 Trellis 父/子任务管理推进。未获额外授权不推送远端或发布包。
