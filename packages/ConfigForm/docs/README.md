# ConfigForm Studio 文档

ConfigForm 的 Runtime 面向开发者手写配置；Studio 面向可视化设计与 Vue 源码交付。
两者的使用入口和产物边界见 [ConfigForm README](../README.md)。

| 文档                                 | 用途                                       |
| ------------------------------------ | ------------------------------------------ |
| [产品定位](./product.md)             | 用户任务、设计资产和产品边界               |
| [架构](./architecture.md)            | 当前分层、配置与代码关系、包依赖和版本     |
| [实施计划](./implementation-plan.md) | 本轮范围、验收与后续顺序                   |
| [未来源码导入](./source-import.md)   | 部分导入、动态受限区域与导出要求；尚未实现 |
| [验证](./verification.md)            | 验证场景、命令与本轮执行结果               |

当前已有项目与资产管理、真实组件设计与预览、表单响应式布局、静态视觉属性、校验、
示例数据、本地交互、源码生成、Studio SDK、本地工作区与 MCP。具体 API 以各包 README
为准。当前收尾聚焦两种开发路径的入口、文档、编辑顺序与交付体验，完成后冻结功能范围。

包入口与用法见 [ConfigForm README](../README.md)。旧产品文档和历史验收记录通过
Git 历史查阅，不保留第二份定位或路线图。
