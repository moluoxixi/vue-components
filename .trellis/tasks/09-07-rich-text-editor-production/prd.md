# 补齐富文本编辑器生产契约

## 目标

完成未落地的 P1/P2 并修复重构的交互、样式回归，以真实浏览器和发布包证据验收。

## 范围

- 内置命令共享执行、能力和激活态来源，提供高层命令与增量工具栏插槽。
- 事件订阅生成状态快照，覆盖选区、外部命令、禁用/只读和销毁。
- 保持 HTML API，增加独立 JSON model、确定的优先级和错误/回写契约。
- 创建期扩展支持 Node/Mark，检测重名，定义版本兼容边界。
- 链接输入、粘贴、导入执行统一协议政策；无效输入不删除链接。
- 修复子组件样式、嵌套表单、焦点恢复；完善中英文文档。
- 包级检查、真实 tarball 的 Node/类型/CSS/浏览器及 TipTap 矩阵。

## 不在范围

不 fork 内核，不增加图片、表格、协同服务。保留原始 Editor 兼容接口，常规调用使用 commands。

## 验收

- [x] 命令与 UI 状态同源，高层命令遵循禁用/只读。
- [x] HTML/JSON 不回环，等价内容不重置选区，错误内容保留当前文档。
- [x] 扩展、链接、生命周期和 API 有行为测试。
- [x] 桌面/移动样式、增量工具栏、宿主表单与焦点流程通过浏览器测试。
- [x] 质量检查、安装包、版本矩阵和文档/规范完成。
