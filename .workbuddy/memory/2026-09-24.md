## 把自搓的 button 换回 Element Plus

用户："我们不是引入了 element 吗？怎么不用？"

- 管理台导航标签、页面管理面包屑、页面名跳转三处从原生 `<button>` 换成 `ElButton`；
  链接用 `link type="primary"`，颜色仍走 `var(--wb-accent)`、hover 下划线自己补。
- **坑 1**：`ElButton` 把插槽包进**一个 `<span>`**，`display: grid` 写按钮上只会有一行 ——
  竖向"图标在上文字在下"要写 `.tab.el-button > span { display: grid; gap: 4px }`。
- **坑 2**：EP 的 `.el-button.is-text` 是 (0,2,0)，管理台样式表是全局 CSS（无 scoped 加成），
  覆盖要写成 `.management-shell__nav .management-shell__tab.el-button`（0,3,0）。
- 定位手法：临时 Playwright 脚本 evaluate 出 `className / computed display / height / padding` + `outerHTML`。
- 保留原生 `<button>`：`role="tab"/"option"` 复合控件、整行可点的表格行、设计器自带的
  `mx-config-form-designer__icon-button`、44px 移动端 dock。约定已写入 spec「Workbench Control Set」。
