# ConfigForm 工作流升级审核指南

分支：`codex/config-form-studio-upgrade`。本轮直接按研发阶段合同演进，不添加旧代码或旧模板
兼容层。目标是让字段创作、规则验证、数据模拟、体验检查和源码交接形成完整的工作流。

## 启动与入口

在仓库根目录执行：

```powershell
pnpm test:config-form-packages
pnpm --filter @config-form/workbench dev --host 127.0.0.1 --port 4331 --strictPort
```

打开 <http://127.0.0.1:4331/>，创建一个项目，然后直接新建页面，或通过「从模板创建」选择
审批、问卷等设计。项目创建时选择 Element Plus 或 Ant Design Vue，项目内只展示可用的
模板。顶部语言按钮可以切换中文；设计、体验、交付分别对应作者工作区、实际运行和源码查看。

## 数据表阅读优化

数据表默认使用阅读视图：普通文本采用 13px 字号，数字右对齐，列宽按内容样本分配，
表头和原始行号固定。布尔值、`null`、空字符串和未设置字段分别呈现；长文本可开启换行。
数据集编辑区域在桌面扩宽，分页与保存保持可见。

单击单元格查看完整内容，对象和数组会格式化为 JSON；可直接复制。双击、F2 或「编辑内容」
进入编辑，修改单元格有标记与计数，并可单独撤销。输入不合法或包含模型禁止的属性时，
保存会保留草稿以便修正。点击列名依次切换升序、降序和原始顺序，原始行号始终不变；
排序与搜索不会重排持久化数据，也不会改变修改目标。搜索包含未保存内容。

建议审核：对数字列排序后修改一格、搜索新值、保存并导出；检查原始行顺序、数字类型与
`001` 等文本标识符保持准确。桌面详情位于表格右侧，窄屏详情在表格下方。

## 界面与交互体验优化

项目页优先展示可继续设计的项目，支持按最近更新或名称排序，长项目名可换行。
打开项目时显示进度并防止重复打开。首次访问直接引导创建，项目搜索没有结果时提供
清除入口，清除后焦点回到搜索框。

设计器左侧入口采用图标和文字，收藏星标持续可见，并提示点击添加、拖拽定位。
空收藏、空最近、组件搜索和图层搜索分别给出下一步操作；结果数量随筛选更新。
属性面板放大分组、标签和辅助文字，长标签与继承提示可以换行。常用设置优先展开，
空的辅助文案和高级设置默认折叠；已有文案的字段自动展开辅助文案。说明、帮助和提示
支持多行编辑。搜索临时展开匹配项，清除后保留原有折叠选择并恢复输入焦点。

命令中心保留禁用操作并显示原因，方向键跳过禁用项，列表变化时保持有效选择。
输入法组合输入不会触发执行。搜索无结果时可以返回全部命令，Tab 可直接到达关闭入口；
关闭后焦点返回原操作位置。窄屏弹窗限制高度，搜索和操作提示保持可见。

问题面板分别显示错误、警告和提示数量，按严重程度排序。可以直接筛选和定位页面、
字段或数据；原始诊断码与路径收在详情中。当前分类没有结果时会提示其他分类仍有问题，
只有全部检查通过时才显示通过状态。

建议审核：在名称字段尝试使用已有字段名 `role`，检查拒绝修改后原值保持正确；展开问题
面板，切到警告分类，再返回全部并定位字段。随后用命令中心搜索已保存的保存操作，检查
禁用原因、方向键、输入法、清除搜索和关闭后的焦点。

## 项目、模板与页面管理

全局导航提供「项目管理」和「模板管理」。页面管理收在项目内部：打开项目进入页面列表，
从设计器也可以返回当前项目的页面管理，不另设全局页面管理入口。

「新建页面」直接打开空白设计器，旁边的类型菜单可以直接新建弹窗、抽屉。弹窗和抽屉在
画布中展示自己的标题、容器和遮罩，空白提示位于容器内部。「从模板创建」作为可选入口，
按当前项目组件库和组件合同提前过滤，避免先选中模板再被告知不兼容。没有首页的项目也
可以先设计并保存弹窗或抽屉；添加普通页面后可以运行项目体验。

打开 <http://127.0.0.1:4331/#/templates>，可搜索模板，按类型、组件库、来源筛选，并预览实际
运行界面。「新建模板」填写名称、选择类型和组件库后直接进入模板设计器，可添加组件、
编辑属性、撤销重做、切换桌面/平板/手机，并调整弹层标题和尺寸。模板手动保存，支持
`Ctrl/Cmd+S`，离开未保存设计时会提示。窄屏可以切换组件、画布、属性区域。

内置模板可预览，点击「基于此模板设计」创建个人副本。个人模板可编辑、复制、删除；
项目页面的「更多」菜单也支持「存为模板」。模板库使用独立的本地存储，不产生额外项目
卡片；应用模板生成独立页面副本，删除或修改模板不会改变已经创建的页面。

当前可复用模板包含独立页面设计，不打包其他页面、数据集或资源。保存时会拒绝未移除的
外部引用并给出说明；模板需要在使用相同组件库的项目中应用。

建议审核：新建空项目，直接创建抽屉并添加组件，刷新检查自动保存；新建弹窗模板，修改
标题和尺寸，添加字段后保存、刷新、预览；将项目页面存为模板后再次应用，检查设计和
原页面互相独立。切换到 390px，检查创建窗口、模板筛选和设计器的保存操作。

## Runtime 宿主能力

以下 API 由生产宿主配置，Studio 当前没有全部提供可持久化编辑入口：

| API                                  | 行为                                                              |
| ------------------------------------ | ----------------------------------------------------------------- |
| `errorSummary` / `errorSummaryLabel` | 展示校验问题摘要，点击可定位具体字段实例                          |
| `focusFirstError`                    | 提交存在校验问题时滚动并聚焦首次错误，可关闭；重复字段按实例定位  |
| `scrollToFirstError()`               | 主动揭示首次错误实例                                              |
| `loadingText` / `validatingText`     | 提供可访问的加载和校验状态文本                                    |
| `stickyActions` + `actions` 插槽     | 固定长表单操作区；插槽提供值、状态、`submit()` 和 `resetFields()` |

Element Plus 与 Ant Design Vue 包会转发 `actions` 插槽。字段支持文本使用
`aria-describedby` 关联控件。源码生成同步保留字段文本和表单布局，宿主的上述额外展示
策略需要程序员在交付代码中配置。说明、帮助和警告中的 HTML 字符与 `{{…}}` 保持为
字面文本，不会作为生成模板的标记或表达式执行。

## 实现边界

- 项目、Surface 和规则仍通过严格的当前合同 Reader 校验；所有正式作者变更通过
  command/transaction/history，编辑器样例、搜索、弹窗和草稿不写入 ProjectDocument。
- Dataset 单元格草稿仅保留在当前会话，刷新前应保存。表格一次只渲染当前页；数字、布尔、
  对象沿用现有类型，新增文本列保持字符串，嵌套值以 JSON 编辑。
- CSV 支持引号、逗号及换行；导入保留字符串值以保护 `001` 等标识符。当前不支持 Excel。
- JSON Schema 只导入平面对象中的 primitive 字段，支持 nullable、枚举、默认值、Required
  和受支持的校验。`$ref`、嵌套对象/数组、组合 schema 等会报告不支持，不会静默降级。
- 条件树支持字段值路径、比较和 AND/OR/NOT，编辑深度上限为 6；其余安全 AST 用高级
  JSON 编辑。执行安全边界由已有白名单 schema/求值器控制。
- 布局复制只复制表单列数、默认跨度与标签宽度，不复制每个字段的独立 placement。
- Studio 使用本地静态数据，没有增加 HTTP、任意 JavaScript/CSS、Flow 或多人协作。
  Designer、Prototype Runtime 和 Source 保持独立职责；原生 Vue 交付不依赖内部解释器。
