# 全局前端规范

本目录包含适用于仓库内所有前端包、应用、Playground 和文档站的共享
实现合同。包级规范可以增加更严格的约束，但不得降低这里的质量门槛。

## 开发前检查

- 新增或重做 Tooltip、Popover、Select、Combobox、Dropdown、Menu、Dialog、
  Drawer、Tabs、DatePicker 等通用交互组件前，阅读成熟组件库优先合同。
- 先检查目标包已经使用的组件库、仓库共享组件和依赖，再决定实现方式。
- 若决定手写成熟组件库已经覆盖的交互，必须先记录不可复用的具体约束和
  等价质量验证；“样式更方便”或“代码不多”不是有效理由。

## 质量检查

- 确认实现没有复制组件库已有的浮层定位、键盘导航、焦点管理、点击外部
  关闭或无障碍状态机。
- 确认组件测试覆盖真实交互合同；仅有 DOM 快照或 CSS 文本断言不够。
- 新增第三方依赖时，确认维护状态、许可证、包体积、SSR/浏览器兼容性和
  当前技术栈集成成本。
