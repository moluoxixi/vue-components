# Utilities

The utility packages share this repository's pnpm workspace, Changesets release flow, and VitePress site while remaining independently installable.

English utility reference pages are published when a package provides an explicit
English README source. The current utility packages only publish Chinese README
content, so no untranslated detail pages are linked from this locale.
